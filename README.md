# flowpilot

Day 3 goal: **CRUD properly.** Understand the backend, don't copy it.

## Where you are now

`app/main.py` already has `GET /health`, `GET /requests`, `POST /requests`,
`GET /requests/{id}` using an in-memory dict.
The model is incomplete: no `status`, no `created_at`, and there is no **DELETE**.

## Day 3 checklist

- [ ] Add `status` and `created_at` to the model.
- [ ] Add `DELETE /requests/{id}` (return `204` on success, `404` if missing).
- [ ] Separate the three model responsibilities (this is the whole point of Day 3):
  - **request model** — what the client sends (`RequestCreate`)
  - **database model** — what you store (id, status, created_at live here)
  - **response model** — what the client gets back (`response_model`)
- [ ] Make `created_at` generated by the server, not the client.
- [ ] Add tests in `tests/` using `TestClient` (create -> read -> delete -> 404).


Open http://127.0.0.1:8000/docs and test every endpoint by hand.
